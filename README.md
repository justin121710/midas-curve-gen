# 線形建模器 — midas Civil

把線形表算成 **midas Civil 的 `.mct` 幾何**(節點 / 元素 / 結構群組)的網頁工具。
單一 HTML 檔、純前端、不需安裝也不需後端 —— 打開就能用。

**線上使用:** https://justin121710.github.io/midas-curve-gen/

---

## 這是做什麼的

補 midas 不擅長的**空間線形建模**,不是產生一整座橋。

**一個群組 = 一串節點 + 連接它們的元素。** 群組之間預設互不相干,起終點在全域座標直接給。

對象是拿到線形表數字、但手上沒有 Civil 3D 的結構工程師。真正的競爭對手是 **Excel 逐樁號手算**
與 **midas 內建的 Rotate Copy**(單一等半徑圓弧用內建的還比較快)。這個工具的差異只在:

- 即時 3D 預覽(可自由旋轉,滑鼠操作與 midas 一致)
- 多段緩和曲線自動切線銜接
- 一次輸出節點 + 元素 + 結構群組
- 弦線偏差自動檢核

## 群組

| 族 | 型別 | 定義方式 |
|---|---|---|
| 幾何 | **線** | 一串段:直線 / 圓弧 / 懸垂 / 螺旋 / 線形鏈 / 單點 / **座標表**;段與段共用接縫節點 |
| 連接 | **對接** | 兩個群組的節點依配對方式連接:一對一 / 錯開 n 格 / X 形交叉 / 依比例對應 / 連到最近節點 / 自訂連接方式(自己畫樣式單元,或在 3D 視圖點兩個節點帶入) |
| 連接 | **垂落** | 每個節點垂直連到**固定高程 / 斜面 / 另一個群組對應節點的高程**,可指定節點範圍 |
| 連接 | **扇出** | 一點(自訂座標或**某群組的第 k 個節點**)連到某群組的節點區間,可分割 + 垂度 |

圓弧有三種定義方式:端點 + 半徑、圓心 + 轉角,以及**三點(任意平面)**——
傾斜的拱肋、斜置的環不必先想是水平還是鉛直。
座標表可以直接從 Excel 整塊貼上,每行前三個數字就是 X / Y / Z,標題列自動跳過。

任何群組都可以:**整個群組平移 / 旋轉 / 鏡射**、**位移複製**(可選「獨立」連上游一起複製,
或「連動」仍掛在原來源)、**沿線陣列**、**自訂顏色**。鏡射平面選 X / Y / Z 再給位置即可,
位移量留 0 就是純鏡射複製。

要**補一個算不出來的點**,加一個**節點段**;要**在兩個既有節點之間補一根元素**,
加一個**直線段**、起點與終點各指到「某群組的第 k 個節點」、分割數填 1 即可
—— 兩端會由「合併重合節點」接回原來的節點,而且上游重新分割時會自己跟著走。

**沿線陣列**把一個群組沿另一條線複製好幾份 —— 橫隔板、橫繫、等距墩柱都是這樣鋪出來的。
位置可以是路徑上每個節點一份、沿弧長等分 N 份,或每隔固定距離一份;
勾「跟著線轉向」就會沿切線方向轉,第一份維持原朝向。

3D 視圖裡**只有正在編輯的群組保留顏色**,其餘一律畫成黑色的線,
編輯中的群組節點會畫得比線粗、外圈加白邊,不會被自己的線蓋掉。
**在圖上點任何群組的節點或元素,就會直接切到那個群組的編輯介面**;
**滑過去的時候左側清單那一列也會跟著亮**(反過來滑清單會在圖上亮,兩個方向都有)。

線群組裡每一段的**起點與終點可以指到同群組任何一段的 起點 / 中點 / 終點,也可以指到
別的群組的第 k 個節點**(下拉選,或直接在 3D 視圖上點那個節點)—— 跨群組對齊不用再自己抄座標。
存的是序號不是節點編號,所以上游重新分割也不會錯位。

介面上的說明預設收起來,每個區塊標題右邊一顆 **i**,點了才展開。
統計數字在左欄底下;右上角是**編號設定 / 施工階段 / 匯入 / 匯出**四顆全域按鈕
——**再按一次同一顆就關掉**。標題列的**群組欄**可以把左側清單整個收起來,把空間讓給畫布。
**匯入**可以選檔案或直接貼上文字 —— 本工具的參數檔、或 midas 匯出的 .mct
(讀 `*MATERIAL` / `*SECTION` 的名稱,之後材料 / 斷面欄位就顯示名稱而不是編號;
帶幾何的完整模型還可以設成**目標模型**或**反向匯入**,見下一節)。

左欄是**單行極簡**(預設 150 px):一列只有圖示 + 名稱,節點 / 元素數滑過去才顯示。
線群組只有一種段時,圖示直接畫那一種段(直線 / 圓弧 / 懸垂 / 螺旋…)。
**群組可以多選**(Ctrl / Shift,和檔案總管一樣),一起位移複製、啟用、停用或刪除;
一起複製時它們之間互相的參照會改指到複本。
**沒選任何群組時,編輯區會整個收起來**,空間讓給畫布;點任一群組(或圖上的節點 / 元素)就滑回來。
新群組的元素類型 / 材料 / 斷面**預設留空並攤開**,提醒你還沒設定;填完就自動收合。
畫布右上角的視角九宮格按下去會**順便重新框選**,和 midas 一樣。

以下是舊版的說明:每一段的起點與終點
不必再照順序一段接一段(循環參照會報錯,不會當掉)。
座標重合的節點**預設會自動合併**(同一位置只留編號最小的那個,等同 midas 的 Merge Nodes),
所以指到同一點的幾段是真的接在一起,不是各自獨立的重合節點。

## 用法

1. 開網頁 → 左側「+ 新增群組…」,或按「載入範例」挑一個現成的模型
   —— **人行吊橋**(主索 + 吊索 + 塔架 + 橋面下桁架 + 抗風索系統)、**公路橋梁**(緩和曲線 + 豎曲線 + 墩柱)、
   **螺旋人行步道**(半徑 5.5 m、坡度 8%、6⅙ 圈、進出口夾 120°,內外護欄 + 內側斜索 + 連續外柱),三個都做到可以直接匯出。
   **三個範例都附了施工階段表**,載入後按「▤ 施工階段」拖時間軸就看得到架設過程
2. 在右側屬性面板設定形狀、分割方式、元素類型與編號
3. 看 3D 預覽與檢核面板(弦線偏差、最短元素、編號衝突)
4. 「輸出」→ 下載 `.mct`,在 midas Civil 匯入

**存檔與還原:** 匯出的 `.mct` 檔頭嵌了完整參數,把檔案**拖回頁面**就能還原全部輸入重編。

## 接到既有的 midas 模型上

把 midas 匯出的**完整模型** .mct 讀進來(選檔、貼上、或直接拖進頁面),會問你要拿它做什麼:

- **設為目標模型** —— 只記下它用掉哪些節點 / 元素編號。
  midas 匯入 MCT 時**遇到已存在的編號是直接覆蓋、不會問也不報錯**,座標一被改掉,
  掛在上面的支承、荷載、施工階段就整批錯位。設了目標模型之後匯出前會先警告,
  「編號總表」也會多一顆**跳到安全號段**,一鍵把起始號推到安全區。
- **反向匯入幾何** —— 節點 / 元素 / 群組讀成一批**「匯入」群組**,**編號原樣保留**。
  這種群組沒有參數(不能改半徑、不能重新分割),但可以**被新構件參照**
  (段的起點 / 終點指到「這一組的第 k 個節點」,直接接到舊模型上)、
  可以整組平移 / 旋轉 / 鏡射 / 位移複製 / 沿線陣列。
  `*GROUP` 沒收到的東西會進 `_UNGROUPED`;複製一份要改編號時用面板上的**編號偏移**。
  匯出時元素**原樣寫回原本的資料列**,纜索那類的 `iSUB` / `EXVAL` 欄位不會被重新猜過。

## 線形要素表(交點法)

線形鏈除了原本的元素法(直線 L / 圓弧 R·Δ / 緩和 Ls),還可以直接用**平面線形要素表**的
交點法輸入 —— 段卡片上打開**「用交點法(IP + R + A)輸入」**:

| 欄位 | 說明 |
|---|---|
| **X · Y** | 交點(IP)座標 |
| **R** | 圓曲線半徑 |
| **A(進) · A(出)** | 兩側的緩和曲線參數;勾掉「用 A 值」就直接填 `Ls`,填 **0** = 該側沒有緩和曲線 |

**偏向(左 / 右)與起始方位角都由座標自動判斷**,不必自己填。工具算出切線長 T1 / T2 與圓弧偏角,
展開成原本的子段串,後面的分割、樁號、縱斷面全部照舊。

- **切線長是用實際畫出來的那條緩和曲線數值積分算的**,不是級數近似 —— 和圖面完全對得起來。
- **非對稱(兩側緩和曲線不等長)也成立。**
- 「整表貼上」可以從 Excel 整塊貼過來,每行取前 5 個數字 = X · Y · R · 進側參數 · 出側參數,
  標題列自動跳過;按「套用這張表」才會寫進交點表,貼上的原文會留著方便回頭核對。
- 算不出來會**報錯**而不是靜靜畫出怪東西:偏角容不下兩段緩和曲線、兩個交點太近放不下切線長、
  偏角接近 0 或 180°,三種情形各有各的訊息。

## 施工階段群組

懸臂或節塊工法要把主梁切成幾十個節塊群組,在 midas 裡是「框選 → 新增群組 → 命名」重複幾十次,
框錯了也沒人會告訴你。群組面板上打開**「施工階段群組」**就一次生出來,三種切分規則:

| 規則 | 輸入 | 適用 |
|---|---|---|
| **每 n 根元素一組** | n,或分組表 `2@3 8@4`(2 組每組 3 根、8 組每組 4 根) | 等節塊 / 變節塊 |
| **對稱懸臂** | 墩心是第幾個節點 | T 構懸臂 —— 兩側各自由內往外編號,名字帶 `L` / `R` |
| **依樁號分界** | 一串樁號 | 合龍段、支撐架分界(要線形鏈段才算得出樁號)|

**產生的只是額外的 `*GROUP` 行,幾何完全不動**;原本整組的群組也保留,
所以 midas 裡「全橋」和「逐節塊」兩種選取都在。

> **對稱懸臂的「墩心是第幾個節點」會被「合併重合節點」影響** —— 墩頂與主梁交會處的重合節點
> 被併掉之後,該群組的節點序號會跳。面板上會顯示**墩心實際落在哪個節點與座標**,對一下再調。

## 時間軸

標題列的 **▤ 施工階段** 進去按「自動排一份順序」,就有一張階段表(名稱 / 天數 / 啟用哪些結構群組),
上面一條**時間軸滑桿**:

時間軸只在這一頁作用 —— 點圖面或按一下「施工階段」離開,畫面就恢復顯示全部。
滑桿的值是**已經蓋到第幾階段**:**最左邊 = 開工前,一根都還沒蓋;拉到最右邊才是全部顯示**;
中間第 k 格 = 第 1 到 k 階段已啟用,**之後的畫成很淡的灰**。整座橋長什麼樣、現在蓋到哪,
同時看得到;啟用是**累積**的。

階段少的時候滑桿一格很大,用兩側的 **◀ ▶** 一階一階走,**⏮ ⏭** 直接跳到開工前 / 拉滿。
切錯一格、左右不對稱、漏一個節塊,走一遍就看見,不必等 midas 跑完階段分析才發現。

**啟用的群組用「+ 群組」挑,不必記名字** —— 視窗裡會標出每一組已經被哪個階段收走
(「已在 CS05 縱橫梁 DECK」),一眼看得出還有誰沒排到;有元素卻沒排進任何階段的群組
會在檢核面板出警告(那在 midas 的階段分析裡會永遠不啟用,而且沒人會告訴你)。

**三個範例都附了現成的階段表**,可以直接拖時間軸看架設順序:

| 範例 | 階段 |
|---|---|
| **人行吊橋** | 塔架 → 主纜 → **抗風索** → 吊索 → 縱橫梁 → 底部桁架 → 抗風支索 |
| **公路橋梁** | 下部結構(墩柱 + 承台繫梁)→ 墩頂橫梁 → 上部結構 → 附屬 |
| **螺旋人行步道** | 中央柱 → 坡道與外柱 → 吊索 → 護欄 |

> 吊橋的**抗風索刻意排在橋面之前**:它兩端錨在岩壁、完全不依附橋體,而人行吊橋施工中最怕的
> 就是橋面的橫向擺動 —— 抗風系統要在橋面上去之前就到位。真正必須等橋面的是**抗風支索**
> (它把桁架下弦拉到抗風索上),所以那一項留在最後。

階段表除了名稱與天數還可以填**材齡**,一起寫進 `.mct` 的 `*STAGE`:

```
*STAGE
   NAME=CS01_TOWER, 60, YES, NO
     AELEM=G_TOWER_W, 28, G_TOWER_E, 28
   NAME=CS02_CABLE, 30, YES, NO
     AELEM=G_CABLE_L, 0, G_CABLE_R, 0
```

`bSAVESTAGE` / `bSAVESTEP`(結果要不要按階段 / 按 Step 存)逐階段填只是噪音,
集中在面板下方設定,寫進每一個階段。

**邊界與荷載的啟用不在這裡設。** midas 的荷載多半跟結構綁在一起
(例如 `beam element load` 要作用在特定元素上),支承也一樣 —— 這些都得先把模型匯進 midas
才設得了,在這邊先開空群組省不到任何事。匯進去之後在 midas 的施工階段對話框裡補上即可。
**收縮潛變、材齡函數、載重組合同理** —— 那是工程判斷,不是幾何。

> 欄位依 midas 官方手冊的 `*STAGE` 定義,只輸出 `NAME=` 與 `AELEM=` 兩種行。
> **尚未用實機樣本比對的部分**:`YES` / `NO` 的字面寫法、省略整行是否合法。
> 第一次匯進 midas 請先確認階段有沒有正確建起來。

## 斷面沿樁號變化

變高箱梁、加勁段這種「斷面沿樁號換」的情形,在 midas 裡要一根一根點。
群組面板打開**「斷面沿樁號變化」**貼一張表就逐元素寫進 `iPRO`:

```
0k+000  0k+060  2
0k+060  0k+140  3  1
140     220     2
```

一行一個區間:**起樁號 迄樁號 斷面編號 [材料編號]**,空白或逗號分隔,樁號吃 `0k+060` 或純數字。
元素歸屬看它的**中點樁號**(要**線形鏈**段才算得出樁號);落在表外的元素**維持原本的斷面**,
不會被清掉。元素屬性因此變成三層,**最細的贏**:整組預設 → 段覆寫 → 樁號區間表。

## CAD 圖(.dxf)

匯出面板多一顆 **CAD 圖 .dxf** —— 每根元素一條 3D 線、每個節點一個點,
**圖層 = 匯出群組名**,顏色對到最接近的 ACI 索引色;節點 / 元素編號可另外輸出到
`NODE_NO` / `ELEM_NO` 圖層(預設關)。拿回 CAD 疊上道路平面圖核對,或給道路組確認。

**`.dwg` 做不到** —— 那是 Autodesk 控制的封閉二進位格式,純前端寫不出來。
但 AutoCAD / BricsCAD / Civil 3D / Rhino 全都直接讀 DXF,要 `.dwg` 在 CAD 裡另存即可。

## 幾個要知道的事

- **單位:輸入什麼單位就算什麼單位,匯出也是同一個單位,全程不換算。** 單位在最上方標題列設定,預設 `m` / `kgf`。
- **匯出的 `.mct` 是純 ASCII。** midas 匯入常以系統 ANSI 編碼讀取,中文會變亂碼,而 `*GROUP`
  的名稱是功能性欄位。組名全中文時會退回 `G01` 序號 —— 想看到有意義的群組名請在組名裡帶英數。
- **元素 beta angle 一律為 0**(斷面正置)。斷面要傾轉(I 型梁強弱軸朝向、墩柱斷面朝向、超高)
  請在 midas 裡框選群組自行設定 —— **這是刻意的決定**:既然群組已經輸出了,在 midas 裡改的速度
  差不多,而且那裡看得到斷面實際的角度。(這也是為什麼一定要輸出結構群組。)
- **節點之間是直線元素**,模型是內接於真實曲線的折線;工具會即時顯示弦線偏差,
  但分割密度的最終判斷仍在使用者。
- **分割方式有五種,量的東西各不相同**:
  「指定元素數」等分曲線參數(直線 = 等長、圓弧 / 螺旋 = 等圓心角、懸垂 = 等弦線水平投影、
  線形鏈 = 每個子段各自切 N 根);
  「指定間距」量的是**沿曲線的 3D 弧長**,所以實際元素(弦線)會**略短於**設定的間距;
  「軸向間距」量的是 **X / Y / Z 某一軸的座標差**,元素長度 = `d ÷ 方向餘弦 ≥ d`;
  「間距表」照 midas 的寫法直接打一串,例如 `3 36@4 3` = 3 + 36×4 + 3 = **150**、38 根元素
  (`n@d` = n 段每段 d),量測方向可選沿弧長或某一軸;
  「弦線偏差容差」量的是曲線離弦線的最大垂距。
  段卡片的「分割與元素覆寫」裡會直接列出**曲線長(弧長)**與**元素弦長 min–max**,兩個數字可以對照。
- **不適合用來「改」既有模型的幾何**。元素數量一改,既有的支承、邊界、荷載、施工階段就會錯位;
  定位是建模階段的幾何生成。但**往既有模型加新構件是可以的** —— 用上面的「目標模型」擋掉撞號,
  用「反向匯入」把舊模型讀回來當定位基準。
- **材料 / 斷面可以顯示真正的名稱**:先在 midas 建好斷面與材料,Export 一份 `.mct` 拖進本工具,
  欄位就會變成「2 — SM570」這種下拉,不用再對編號。(名稱只是顯示用,輸出的仍是編號。)

完整的限制清單見 [SPEC.md](SPEC.md) §12。

## 開發

程式全部在 `index.html` 一個檔案裡,沒有建置步驟。改完直接用瀏覽器開即可。

**內建 732 項自動驗收測試**,頁面底部的「驗收測試」展開就看得到,每次載入都會跑。

改程式前先跑語法檢查 —— 單檔 HTML 的語法錯誤在瀏覽器裡是**無聲的**,
整份 script 不會執行、頁面靜默半殘:

```bash
node -e "const fs=require('fs');const m=fs.readFileSync('index.html','utf8').match(/<script>([\s\S]*)<\/script>/);fs.writeFileSync('/tmp/_c.js',m[1])" && node --check /tmp/_c.js
```

規格與設計決策、踩過的坑、MCT 格式的驗證紀錄都在 [SPEC.md](SPEC.md)。
`index-v*-backup.html` 是各版本的備份。
