# tools/cable_pretension.py — 吊橋纜索的初張力與無應力長度

`index.html` 只管幾何:纜索元素的 `EXVAL` 預設是 0,要你自己到 midas 裡一根一根填。
這支 Python 程式補上這一步:**讀 midas-curve-gen 匯出的 `.mct`,依恆載平衡算出每根纜索的張力 $T$ 與
無應力長度 $L_u$,把 `EXVAL` / `EXVAL2` 填回元素列**,再交給 midas 做幾何非線性分析或找形。

它刻意留在 `index.html` 外面(SPEC §16.0:需要工程判斷的東西不進幾何工具)——
載重、$EA$、耐風索的設計張力都是工程判斷,這裡只負責把判斷**算成數字並寫進正確的欄位**。

只用 Python 標準函式庫,`python3 cable_pretension.py` 就能跑。

## 兩種用法

```bash
# 1) 參數式:與《Midas Civil 橋梁結構分析與設計實務》附錄 B 第 1 版相同的 60 m 例題
python3 cable_pretension.py --demo

# 2) 接 midas-curve-gen
python3 cable_pretension.py model.mct roles.json -o model_tensioned
```

第 2 種用法的輸出:

| 檔案 | 內容 |
|---|---|
| `model_tensioned.mct` | 纜索元素的 `EXVAL` / `EXVAL2` 已填好;其餘資料列**原樣保留**(含參數區塊) |
| `model_tensioned_report.csv` | 每根纜索的弦長 $L$、水平投影 $L_h$、張力 $T$、水平分量、$EA$、$L_u$、$L_u/L$ |
| `model_tensioned_tie_eq.csv` | 繫索作用在橋面節點的力(`TIE_EQ` 工況),欄位依 midas 的 Nodal Loads 表格:Node、Load Case、FX、FY、FZ、MX、MY、MZ |

> 把輸出的 `.mct` 拖回 midas-curve-gen 會依參數**重建**幾何 —— `EXVAL` 與修正過的節點座標不會保留。
> 要改幾何就回到工具改參數、重新匯出,再跑一次這支程式。

## 角色設定檔(roles.json)

範例見 `examples/suspension_demo_roles.json`(對應工具內建的「人行吊橋」範例,單位 kN、m)。

| 欄位 | 說明 |
|---|---|
| `main` | 主纜群組(可含兩側控索;一組 = 一條不分岔的節點串) |
| `hanger` | 吊索群組;上端接在主纜節點上 |
| `wind` / `tie` | 耐風索(抗風索)與繫索(抗風支索)群組,可省略 |
| `saddles` | `{ "G_CABLE_L": [15004, 15036] }` 指定塔頂節點;省略時取節點串上最高的兩個局部極大值 |
| `loads.deck_per_len` | 每一索面的橋面恆載(力/長度);依吊索的分擔長度分給各吊索,端吊索分到塔的一半 |
| `loads.band` | 每個吊點的索夾重(力) |
| `loads.w_main` / `w_hang` / `w_wind` | 主纜、吊索、耐風索的自重(力/長度) |
| `hanger_loads` | `{ "節點號": 力 }` 逐點覆寫橋面分擔(例如用 midas 的反力) |
| `EA` | `main`、`hanger`、`wind`、`tie` 各自的軸向勁度 |
| `wind_H` | 耐風索沿其錨碇連線方向的張力分量 $H_w$(設計值) |
| `tie_T` + `fix_wind` | 給定繫索張力並設 `fix_wind: true` 時,以**力密度法**重算耐風索節點,使耐風索成為這組繫索的索多邊形 |
| `fix_main_z` | `true` 時把主纜主跨節點移到索多邊形上(依吊索載重的等值梁比擬),否則只回報差值 |
| `output_kind` | `Lu`(`EXVAL2 = 3`)、`Pretension`(`= 1`)、`Horizontal`(`= 2`) |

**單位一律沿用 `.mct` 的 `*UNIT`,不換算** —— 工具預設是 `KGF`、`M`,載重與 $EA$ 要用同一組單位填。

## 算法

1. **耐風索與繫索**(若有):耐風索各段 $T = H_w L/L_x$($L_x$ 為沿錨碇連線的投影)。每個繫索節點上,
   相鄰兩段張力的合力就是繫索要提供的力 → 繫索張力 $t$,以及它把橋面節點往哪裡拉。
   - 程式檢查兩件事:沒有繫索的節點合力是否為 0、繫索方向與合力的夾角。
     工具的「懸垂」段是拋物線或懸鏈線,**不是**繫索的索多邊形;內建範例的夾角約 7.7°,
     沒有繫索的中間節點也有約 2.1 kN 的不平衡力。
   - 設 `fix_wind` 與 `tie_T` 時改用力密度法(錨碇與繫索的橋面端固定、迭代更新力密度)求平衡位置,
     夾角歸零、每根繫索的張力都等於 `tie_T`。
2. **主纜與吊索**:吊索力 $N_h$ = 橋面分擔 + 繫索向下分力 + 吊索自重的一半;
   主纜節點載重再加索夾、吊索另一半自重、主纜自重。以塔頂連線為弦,
   等值簡支梁比擬 $H f = M_0(L/2)$ 求 $H$,索多邊形 $z(x) = z_c(x) - M_0(x)/H$。
3. **張力與 $L_u$**:主纜與控索 $T = H L/L_h$(塔頂水平力平衡),吊索 $T = N_h$,$L_u = L/(1 + T/EA)$。

## 和 midas 的分工

這支程式給的是**手算等級的平衡初值**:吊索垂直、橋面恆載依分擔長度分配(未計連續梁效應)、
控索的水平分量取與主跨相同。結果一律要在 midas 用恆載幾何非線性分析(或找形)驗證:
加勁梁吊點撓度在 mm 級、所有纜索受拉、主纜 $H$ 與這裡一致。

`TIE_EQ` 的用途:用 midas 的懸索橋找形時,耐風索與繫索**先不建**,
把 `TIE_EQ` 當成恆載工況一起參與找形;找形完成、加入耐風系統元素之後,**拿掉 `TIE_EQ`**
(否則繫索的力會算兩次)。

## 測試

```bash
python3 -m unittest tools/test_cable_pretension.py -v
```

12 項:參數式例題的 $H$ 與第 1 版一致、清單語法、每根纜索都有填值且欄位數為 10、$L_u < L$、
主纜水平分量處處相同、修正後每個吊點的垂直平衡、輸出可重新解析、
幾何不一致時有警告、力密度法收斂到 `tie_T`、繫索橫向分力兩側抵消、不相容的 `tie_T` 會報錯。
