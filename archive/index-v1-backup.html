起始設定

平面線形段落

除第一段外(或勾選「獨立起點」者),每段自動繼承前段終點座標與方位角 → 切線連續。

縱斷面(VPI)

第一列與最末列為起訖點(不設豎曲線)。豎曲線為對稱拋物線,L = 0 表示直接折角。樁號是平面里程——元素的真實 3D 長度會略大於樁號差。

強制節點與吸收

支承中心、伸縮縫、橫隔梁、施工分段、預力錨定、變斷面起訖。容差內的均分節點會被吸收;段落交界與線形端點受保護,不會被移除。

偏置線與橫梁

偏置節點 = 主線同樁號的法線投影,所有線在同一樁號橫向嚴格對齊,橫梁必為直線;代價是偏置線上的節點間距不相等。橫向 右 = 正、左 = 負(以行進方向論);垂直 上 = 正。

主纜(懸索橋)+ 空間轉換

在局部座標(x 沿跨徑、y 橫向、z 鉛直)算出主纜與吊索,再用兩個控制點做 3D 剛體轉換放到全域座標。轉換式為 P_global = R·(P_local − P1) + Q1。

纜索

斜張索建議分割數 N = 1:midas 的 CABLE 元素內建垂度處理(等效彈性模數),切分反而會失去它。N > 1 適用懸索橋主纜,此時必須給垂度——共線的直線節點串在幾何非線性分析中橫向勁度為零。

輸出

畫面上所有長度一律以「公尺」輸入;匯出 .mct 時才換算成上面選定的長度單位(選 MM 就 ×1000),CSV 與檢核面板維持公尺。纜索 EXVAL 請直接填目標單位的值,不換算。
⚠ MCT 格式尚未以 midas 實機 Export 驗證。欄位順序依標準結構撰寫(UNIT → NODE → ELEMENT → GROUP),纜索元素的類型代碼與 EXVAL 欄位是最可能需要調整的地方——上面三個欄位可直接改。實際 Export 一份最小模型比對後,回報差異即可修正。
CSV 含 UTF-8 BOM,可直接用 Excel 開啟。.mct 的檔頭註解嵌了完整參數 JSON,把該檔拖回本頁面就能還原全部輸入重編。若需要 .cst 副檔名,存檔後更名即可。
